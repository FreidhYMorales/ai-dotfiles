## Unnamed risks
- **agy quota gates every agy verification.** Item 8's agy half, item 1's plugin-import half and #17 all need real agy runs; the account hit `RESOURCE_EXHAUSTED` with a 54 h reset and `--mode auto` is unavailable (`stories/03-agy-engram-subagent.md:44`). — High — Split item 8 into "OpenCode verified" and "agy format-verified, run pending"; do not let v1 depend on the agy run, and record the gap in `docs/multi-agent.md`.
- **A generated agy agent fails silently.** Unknown tool or wrong frontmatter means agy never builds the subagent, logs it, and exits 0 (`stories/03-agy-engram-subagent.md:43`); pair would proceed believing the verifier reviewed the branch. — Medium — Story 17 must assert a real report comes back, and pair should treat an empty verifier report as NEEDS DECISION, not PASS.
- **The live install already drifted.** `~/.gemini/GEMINI.md` (85 KB) and the old unread `antigravity-cli/AGENTS.md` link came back after a merge, and story 01's install was not re-run (`stories/03-agy-engram-subagent.md:45`). Nothing checks the live config against the repo. — High (already happened) — Add an `install.sh` summary of the effective rules/skills/hooks paths per target, and re-run install before item 8.
- **herdr rewrites agy's `hooks.json`.** It can drop the `toolkit` key, taking the Stop gate and `prefer-modern-cli` with it (`stories/05-modern-cli-hooks.md:46`). — Medium — Re-assert on every install (already true) and add the note to `docs/multi-agent.md:15`.
- **OpenCode 2.2.2 hangs on an extra plugin file.** Any additional file in `~/.config/opencode/plugins/`, even empty, hangs `opencode run --standalone` (`stories/20-opencode-pause.md:43`), and the install test pins the dir contents to exactly three files (`install.test.sh:271`). A probe left behind during development looks like a broken hook chain. — Medium — Document it in `docs/multi-agent.md`'s manual-setup section and keep probes inside the linked `toolkit.ts`.
- **The OpenCode background service serves stale plugins.** `opencode run` talks to `opencode serve --service`, which loads plugins at start (`docs/multi-agent.md:24`); a smoke run against a stale service reports the old behaviour. — Medium — Make "restart the service" the first step of item 8's OpenCode half.
- **One unmapped tool aborts the whole generation.** `gen.sh` exits 1 on the first unknown agy tool (`gen.sh:96`), and `install.sh` then fails the install (`install.sh:217-221`). Porting jd agents (`Skill`, `Edit`, `Write`, engram tools) would break installs for every target. — Medium — Skip-and-warn per agent, or generate per agent atomically.
